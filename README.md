# 🧮 Dual Calculator

A clean and modern calculator built with **HTML, CSS, and Vanilla JavaScript**.

Perform mathematical operations with a simple interface, interactive controls, and a beautiful gradient design.

<br/>

## ✨ Features

- 🔢 Two separate number input fields
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚡ Instant calculation results
- 🎯 Interactive operation buttons
- 💜 Modern and minimal interface
- 🌈 Beautiful purple and blue gradient styling
- 🖥️ Simple and user-friendly design
